# LAN Chat

**A lightweight browser-based chat app for chatting with friends — no account required.**

Website: https://davidsjonesisthegoat.github.io/lanchat/

## Features

- Real-time messaging
- Short room codes for easy joining
- Room approval requests
- Encrypted messages
- Image sharing
- Runs directly in your browser

## How to Use

1. Open the [LAN Chat website](https://davidsjonesisthegoat.github.io/lanchat/).
2. Create a room or join an existing one.
3. Share your room code with friends.
4. If approval is required, wait for the host to approve your request.
5. Start chatting.

## Privacy and Security

LAN Chat uses encryption to help protect messages. However, encryption does not guarantee complete anonymity or security. Avoid sharing sensitive personal information.

## Technology

LAN Chat is a client-side web application that uses WebSockets to communicate through messaging infrastructure.

## AI-Assisted Development

LAN Chat is an AI-made project, developed with the help of artificial intelligence tools. AI was used to assist with generating and developing the application's code.

## Self-Hosting

You can host your own copy using GitHub Pages or another static web host.

1. Fork or download this repository.
2. Upload the application and any required assets.
3. Configure your hosting provider.
4. Open your published website and share it with friends.

LAN Chat is an independent project. Its availability depends on the website host and the messaging services it uses.
